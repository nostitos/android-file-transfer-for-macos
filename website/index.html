What it does

The everyday parts of moving files, handled properly.

  • Copy both ways

    Files and whole folders, from the phone to the Mac or back again.

  • Drag and drop with Finder

    Drop Mac items onto the phone, or drag phone files straight into Finder, the Desktop, or another app.

  • A queue you can watch

    Progress, speed, and time remaining for each transfer, with cancel and retry.

  • Duplicates handled your way

    Keep Both, Replace, or Skip. Free space is checked before anything copies.

  • Tidy up the phone

    Rename files and folders on the phone, or delete them after a confirmation.

  • Clear about the connection

    Shows whether the cable, File Transfer mode, or the phone's permission prompt is what's waiting on you.

Plug in and copy.

  1. Install

    Open the DMG and drag the app to Applications.

  2. Connect

    Unlock your phone and connect it with a USB data cable.

  3. Transfer

    Choose File Transfer on your phone, allow access if asked, then browse and copy.

Common questions

Is this Google's Android File Transfer?
No. Google's app is no longer offered. This is an independent, open-source project that does the same job.
Do I need to install anything on the phone?
No. Unlock the phone and choose File Transfer (sometimes called Transferring files or MTP) from the USB notification. USB debugging is not needed.
Do my files go anywhere else?
No. Files move over the cable, and the app has no analytics, accounts, or telemetry. Once a day it asks GitHub whether a newer version exists; you choose if and when to update.
Which download do I need?
Apple silicon for M-series Macs, Intel for older Macs. Apple menu › About This Mac shows which you have. Both are signed, notarized, and listed in the published checksums.
Does it work with every Android phone?
It uses the standard File Transfer mode most phones offer, but testing is deepest on Samsung phones so far. If yours misbehaves, an issue report with the phone model helps.
Can I build it myself?
Yes. The source, build scripts, and release automation are on GitHub under the MIT license.
